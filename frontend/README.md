# Shards frontend

Next.js 16 / React 19. Визуальный дизайн, изображения, шрифты и анимации сохранены; логика подключена к собственному API Shards. Покупка скинов — только из внутреннего баланса, прямое пополнение Steam — отдельная оплата. Корзина серверная, избранное хранится на устройстве. Цены, доступность, расчёт дуэта и статусы платежей/выдачи приходят с сервера. Float удалён.

Запуск и полная проверка описаны в [корневом README](../README.md). `npm run dev` запускает UI на 5198; ему нужен backend на 5199. `npm run test:e2e` использует отдельные тестовые fixtures. Коммерческий runtime требует Node-сервер; унаследованный `build:pages` не является поддерживаемым способом публикации коммерческого приложения.

Исходные документы дизайнера (`DESIGN_DIRECTION.md`, `REQUIREMENTS_AUDIT.md`, `project-prompts.md`, `reference-evidence/`) описывают первоначальный прототип. Текущее состояние — в [приёмке](../docs/testing/acceptance-results.md) и [визуальном отчёте](../docs/testing/visual-regression.md).

Hero `public/assets/shards-skins-hero.webp` — оригинальная генерация. Каталожные изображения не менялись, provenance сохранён в `src/data/catalog.json`; этот файл используется только для визуального представления, а не как источник продаваемых цен/наличия. Onest: `public/fonts/OFL.txt`. Материалы Spectra в `reference-evidence` не включены в сайт.
