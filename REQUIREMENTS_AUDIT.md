# Проверка PRISM — 28 сентября 2026

## Выполнено

Семь промптов составлены до реализации; карта визуальных источников записана. Независимая интерфейсная часть всех семи этапов реализована. Готовы главная, каталог, 68 товаров, корзина, кабинет. Steam/баланс сразу после hero, конвертер перед FAQ. Есть сравнение, Duo, избранное, Apple.

## Наблюдаемые браузерные проверки

- 1440: ширина документа 1425 px равна clientWidth, горизонтального скролла нет. Также визуально проверен desktop 1000 px.
- Главная 320/390/768: после исправления min-content Apple блока scrollWidth = clientWidth (305/375/753). На 320 уменьшена иллюстрация карты и заголовок, мобильная навигация компактна.
- Каталог, товар, корзина и кабинет на 390: scrollWidth 375, clientWidth 375. Меню открывается и закрывается при выборе ссылки.
- Duo: бюджет 1 ₽ блокирует добавление и показывает превышение 14 762 ₽; 25 000 ₽ разрешает. Два выбранных предмета появляются в корзине, после reload сохраняются.
- Quick view P250 Undertow: добавление → уведомление внутри dialog:modal, нижняя граница 876 при viewport 900 → ссылка в корзину → модалка закрыта, P250 присутствует. В корзине 3 предмета после добавления к дуэту. Reload сохраняет состав.
- Товар USP-S Printstream: поиск даёт ровно 1 карточку; переход открывает полную страницу. Добавление меняет кнопку на ссылку. После перехода в корзине 4 предмета. Повторный переход через quick view не добавляет дубль.
- Mobile quick view: уже добавленный товар имеет рабочую ссылку. Tab оставляет фокус внутри диалога. Escape в подтверждении выхода закрывает окно и возвращает фокус на «Выйти»; кабинет остаётся открыт.
- Избранное: добавление P250 и фильтр «Избранное 1» дают 1 карточку. Тестовый выбор очищен через UI.
- Диапазон каталога 100 → 1 показывает ошибку. Поиск Printstream даёт 1 товар. Денежные, комбинации фильтров и сортировка дополнительно проверены тестами.
- Steam: ID 123 даёт ошибку 17 цифр. 2 000 ₽ → 100 ₽ → 2 100 ₽. Исправлен origin на порт нового сайта. Публичный Steam profile lookup отвечает; это не подтверждение права на пополнение.
- Баланс: показывает недоступность платежей, не увеличивается.
- Apple: США → Турция сбрасывает подтверждение и блокирует кнопку; сводка 100 TRY. После подтверждения запрос котировки сообщает недоступность, заказ не создаётся.
- Конвертер 3 000 ₽ → 2 000 PRISM.
- Кабинет: неверный trade-URL отклоняется, истории покупок/операций пустые. Реальная Steam-сессия не имитируется. Выход подтверждён через диалог.
- Удаление всех четырёх тестовых товаров приводит к пустой корзине с работающей ссылкой в каталог. Тестовые корзина/избранное и локальный вход очищены через интерфейс.
- У проверенных загруженных изображений товара/корзины naturalWidth > 0. Новых runtime errors в ходе проверок не наблюдалось; dev HMR warning во время изменений не является production ошибкой.
- CSS содержит reduced-motion отключение анимаций, переходов, smooth-scroll; эффект footer также проверяет media preference. Эмуляция системной настройки reduced-motion не проводилась.

## Код и сборка

22 теста проходят: деньги, валидация, фильтры, каталог, Steam, недоступные интеграции, бюджет Duo, дедупликация, fallback storage и cross-tab invalidation. Typecheck/lint/production build проходят. Сборка генерирует 76 страниц/маршрутов, включая серверные endpoints и 68 товаров.

Независимая проверка кода нашла P2: старое localStorage перекрывало memory fallback при quota error. Исправлено с pending writes и invalidation при storage events; добавлены два регрессионных теста.

## Не является завершённым коммерческим запуском

Не предоставлены авторизация Steam OpenID, платежи, актуальный каталог/выдача, поставщик Apple, юридические сведения и подтверждённый бренд. Реальные финансовые операции не выполнялись. UI и локальный preview готовы; эти интеграции остаются отдельной зависимостью.

Проверка Steam после исправления origin нашла реальный публичный профиль и не запускала оплату; проверочный Steam ID не сохранялся. Статическая версия собирается отдельно без API.
